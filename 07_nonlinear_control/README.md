# 非线性控制与综合应用

学习状态：未开始

## 学习目标
- 理解非线性模型、平衡点和局部线性化的含义。
- 通过仿真观察小角度近似的适用范围。
- 综合建模、控制器设计、离散实现和信号处理方法。

## 练习清单
- [ ] 写出非线性摆的运动方程，说明参数和假设
- [ ] 选定平衡点，建立小角度线性模型
- [ ] 在相同初始条件下比较非线性与线性模型
- [ ] 改变初始角度，观察轨迹差异和近似误差
- [ ] 根据所选模型设计反馈控制，并检查适用条件
- [ ] 完成一个电机或其他机电系统的综合仿真项目

## 建议起点
先确定摆角的零点、正方向和所研究的平衡点，使用弧度进行建模。先比较无控制时的小角度响应，再增大初始角度，解释线性近似何时偏离原模型。

比较模型时保持参数、初始条件和仿真时间一致，并记录求解器及误差容限。仿真观察不能直接代替稳定性证明。

## 综合项目方向
在 [电机与 Simulink](../06_motor_control/README.md) 的基础上，依次完成建模、控制器设计、离散实现、加入测量噪声与滤波，并在统一条件下比较控制效果。

## 运行条件
MATLAB 版本和相关工具箱待确认。记录微分方程求解方法；如果使用 Simulink，另行注明其版本和求解器设置。

## 完成标准
- 能说明模型的非线性来自哪里、线性化围绕哪个平衡点进行。
- 用实际仿真结果解释小角度近似的适用范围。
- 综合项目包含可运行代码或模型、关键图像和自己的解释。
- 明确区分实验观察、理论结论和仍待验证的问题。
