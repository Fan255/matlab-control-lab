# 电机与 Simulink

学习状态：未开始

## 学习目标
- 根据电气和机械方程建立直流电机模型。
- 学习在 Simulink 中搭建、运行和记录仿真模型。
- 理解速度环、电流环以及负载扰动对响应的影响。

## 练习清单
- [ ] 整理电机参数、单位和来源，并写出建模假设
- [ ] 根据电压、电流、转矩和转速关系建立模型
- [ ] 比较 MATLAB 模型与 Simulink 模型的开环响应
- [ ] 设计速度闭环，比较参考值跟踪与负载扰动响应
- [ ] 在模型和参数明确后，学习电流内环与速度外环
- [ ] 加入测量噪声、滤波或控制量限幅，比较控制效果

## 建议起点
先学习 Simulink 中的基本模块、信号连接、求解器和数据记录。从简化直流电机模型开始，验证开环响应，再逐步加入反馈控制。

参数可以采用明确标注的教学假设值，不把假设值写成实测数据。本阶段先完成仿真，真实电机实验另行确认设备条件。

## 运行条件
MATLAB、Simulink 和相关工具箱的可用情况待确认。记录仿真所用求解器、步长设置、仿真时长和参数初始化方式。

## 完成标准
- 能解释模型中的电气部分与机械部分如何耦合。
- 模型在注明的参数和环境下可以复现。
- 同时记录转速、电流或控制输入，解释主要响应特征。
- 区分参考值跟踪与负载扰动实验，并说明控制器的适用条件。
