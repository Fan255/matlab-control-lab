# 状态空间与现代控制

学习状态：未开始

## 学习目标
- 理解状态、输入、输出以及状态空间矩阵的含义。
- 掌握能控性、能观性的基本判断方法。
- 学习状态反馈、极点配置、LQR 和状态观测器。

## 练习清单
- [ ] 从一个二阶系统写出状态空间模型
- [ ] 比较状态空间与传递函数模型的输入输出响应
- [ ] 计算能控矩阵、能观矩阵及其秩
- [ ] 通过极点配置设计状态反馈，并比较闭环响应
- [ ] 调整 LQR 权重，比较状态响应与控制输入
- [ ] 设计状态观测器，观察估计误差的变化

## 建议起点
先复习矩阵运算以及 [经典控制](../02_classical_control/README.md) 中的极点概念。从一个简单二阶系统开始，逐项说明状态变量和矩阵维度，再检查模型之间的响应是否一致。

比较不同模型时，先统一输入、初始条件和仿真时间。进行反馈设计前，先检查所需的能控性或能观性条件。

## 运行条件
MATLAB 版本和相关工具箱待确认。使用状态空间建模及控制器设计函数前，在 MATLAB 命令窗口运行 `ver` 检查环境。

## 完成标准
- 能解释模型中每个状态及各矩阵的作用。
- 能说明所选系统是否满足设计条件。
- 同时记录系统输出和控制输入，解释控制效果与控制量的取舍。
- 对观测器实验，记录并解释状态估计误差。
