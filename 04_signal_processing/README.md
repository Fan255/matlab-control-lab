# 信号处理

学习状态：未开始

## 学习目标
- 理解采样频率、采样点数和频率分辨率的关系。
- 学习使用 FFT 观察信号的频率成分。
- 理解噪声、滤波效果与信号失真之间的关系。

## 练习清单
- [ ] 生成已知频率和幅值的正弦信号，并绘制时域图
- [ ] 叠加多个频率成分，使用 FFT 检查频谱
- [ ] 改变采样频率，观察混叠现象
- [ ] 加入噪声，比较含噪信号与原始信号
- [ ] 使用简单移动平均滤波，观察效果与延迟
- [ ] 在工具箱可用时，进一步学习数字滤波器设计

## 建议起点
先构造一个频率已知的正弦信号，预测频谱峰值的位置，再计算 FFT。明确时间轴和频率轴的单位，说明采用的是单边还是双边频谱，以及幅值如何归一化。

加入随机噪声时记录随机种子，让比较实验可以复现。

## 运行条件
MATLAB 版本和工具箱待确认。先学习基础信号生成与 FFT；涉及专用滤波器设计函数时，再检查相关工具箱。

## 完成标准
- 能根据采样条件正确构造时间轴和频率轴。
- 能识别设定的主要频率成分，并解释混叠现象。
- 用同一组输入比较滤波前后的信号。
- 能说明滤波带来的改善，以及延迟或波形失真。
