# 经典控制

学习状态：未开始

## 学习目标
- 理解传递函数、极点、零点与系统动态响应的关系。
- 掌握阶跃响应、根轨迹和频率响应的基本分析方法。
- 理解 PID 参数对响应速度、超调和稳态误差的影响。

## 练习清单
- [ ] 建立一阶、二阶系统的传递函数模型
- [ ] 固定自然频率，比较不同阻尼比的二阶系统阶跃响应
- [ ] 绘制根轨迹，观察增益变化对闭环极点的影响
- [ ] 绘制 Bode 图，学习稳定裕度的含义
- [ ] 比较不同 PID 参数下的闭环响应

## 建议起点
先完成 [MATLAB 基础](../01_basics/README.md)。进入本阶段后，先预测阻尼比变化会怎样影响阶跃响应，再编程绘图，并结合极点位置解释结果。

每次只改变一个参数，记录模型、输入和仿真时间。首次实验可使用 `01_second_order_response/` 子目录，开始实验时再创建。

## 运行条件
MATLAB 版本和已安装工具箱待确认。使用传递函数、根轨迹和控制分析函数前，在 MATLAB 命令窗口运行 `ver`，检查相关工具箱是否可用。

## 完成标准
- 代码可以在注明的运行目录下复现。
- 图像标明标题、坐标、单位和图例。
- 能解释至少一组参数变化对响应的影响。
- 能说明模型假设，以及响应快慢、超调和稳态误差之间的取舍。
