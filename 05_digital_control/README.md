# 数字与微机控制

学习状态：未开始

## 学习目标
- 理解连续模型与离散模型的区别。
- 学习离散化、差分方程和离散控制器的实现。
- 理解采样周期、控制量限幅和执行时序对控制效果的影响。
- 根据实际设备条件，学习串口数据采集与记录。

## 练习清单
- [ ] 对简单连续系统进行离散化，注明所用方法
- [ ] 比较不同采样周期下的系统响应
- [ ] 用循环和差分方程实现离散系统
- [ ] 手写离散 PI 控制器，记录误差、积分状态和控制输入
- [ ] 加入控制量限幅，观察积分累积并研究处理方法
- [ ] 在硬件和接口具备后，完成一次串口数据采集

## 建议起点
从 [经典控制](../02_classical_control/README.md) 中已理解的简单系统出发，先用仿真比较连续与离散模型。明确采样周期、离散化方法和初始条件，再编写差分方程。

手写 PI 时，先推导离散公式，再检查采样周期是否正确进入积分项。串口练习在设备、端口和通信协议确认后再开始。

## 运行条件
MATLAB 版本、相关工具箱和硬件条件待确认。先完成纯仿真实验；涉及串口时记录设备型号、端口、波特率和数据格式。

## 完成标准
- 差分方程实现与参考模型在一致条件下能够对应。
- 能解释采样周期改变后的响应差异。
- 控制器参数、初值和限幅条件记录完整。
- 如完成采集实验，保存真实数据并说明时间轴来源。
